# Multiway Register Machines

An open-source implementation of multiway register machine evolution, with a
browser-based explorer. Companion code for the paper "State Evolution in
Multiway Register Machines Featuring Applications to Recursive Functions."

The engine is pure Python with no runtime dependencies. The web explorer runs
the same engine in the browser, so the site and the paper cannot drift apart.

This is a work in progress. The engine, preset models, and explorer are being
built in phases, and this README will grow with them.
