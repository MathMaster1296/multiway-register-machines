Program diagrams

Boxes are instructions, shaded by the register they touch, with an arrow marker for increment or decrement. Blue arcs are success branches and orange arcs are fail branches. The circle shows the same program as a control graph.

Evolution

States mode merges configurations that coincide, so you get a graph. Tree mode keeps every path separate, so it grows quickly. The caps stop a run that would otherwise go on forever; a banner tells you when one fires.

How to read this

Each chip is one configuration of the machine, written as the program counter and then the register values. An arrow is one rule firing, and its label is the rule's id. The rows are steps: everything in a row was first reached at that step, so the play button and the slider show the evolution unfolding in time.

Click a chip to see where it came from and where it leads. Drag to pan, scroll to zoom, or use the zoom buttons. If the graph is hard to see, the table view lists the same states as text, and every figure can be exported.

Large graph: drawn on a canvas without labels. Graphs under 2000 nodes get the interactive view.
